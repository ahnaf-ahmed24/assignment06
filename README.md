# 🏋️ FITLOG — Gym Companion & Workout Library

FITLOG is a dark-themed, responsive web application built with **Next.js 15 (App Router)** and **Tailwind CSS** that serves as a no-nonsense gym companion.

---

## 🛠️ Technologies Used
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Notifications**: React Hot Toast
- **Deployment**: Vercel

---

## ✨ Key Features
1. ** Interactive Library & Sorting**: Browse all workouts in a 3x4 grid with instant client-side sorting by Duration, Calories, or Rating.
2. ** Dynamic Details Page**: Explore workout specs, equipment, intensity metrics, and step-by-step ordered instructions.
3. ** Today's Plan (Cap of 5)**: Lock lifts into your daily routine with a strict maximum cap of 5 lifts to prevent overtraining.
4. ** Live Metrics Summary**: Real-time aggregation of total exercises, total workout minutes, and total calorie expenditure.
5. ** Persistent Data**: LocalStorage integration retains saved workouts and planned lifts across page refreshes.
